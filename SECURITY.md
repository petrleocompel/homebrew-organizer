# Security policy

## Supported versions

Security fixes are released for the latest minor version only. Self-hosted
instances should track the most recent release.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/petrleocompel/homebrew-organizer/security/advisories/new).
Include the affected version, steps to reproduce, and the impact you observed.

You can expect an initial response within a week. Once a fix is available, a
release is published and the advisory is disclosed with credit to the reporter
unless you prefer to stay anonymous.
